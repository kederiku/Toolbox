# Toolbox

**[Télécharger Toolbox.exe pour Windows](https://github.com/kederiku/Toolbox/releases/latest/download/Toolbox.exe)**

Toolbox est un exécutable portable en français pour Windows 10 et Windows 11. Au démarrage, le catalogue présente les quatorze outils. Cliquez sur une carte pour ouvrir un outil, ou filtrez par famille.

| Famille | Outils |
| --- | --- |
| Matériel | Diagnostic des périphériques et carte USB |
| Réseau | Test de débit, dépannage de connexion et appareils du réseau |
| Système | Performances du PC, bilan de lenteur et intégrité de Windows |
| Fichiers | Téléchargement de vidéos YouTube, convertisseurs d’images, de vidéos et d’audio, ajout de filigrane, nettoyeur de métadonnées et recherche de doublons |

Utilisez **Ctrl+K** pour chercher par nom, usage ou format, par exemple **débit**, **FLAC** ou **EXIF**. Après avoir ouvert une carte, cliquez sur **Retour** ou appuyez sur **Alt+←** pour retrouver votre recherche, le filtre de famille et votre position dans la liste. Pour revoir tous les outils, choisissez **Catalogue** dans le menu.

Dans le menu latéral, dépliez une famille pour ouvrir directement un outil. En fenêtre étroite, cliquez sur **Menu** pour retrouver les mêmes destinations. Si vous partez d’un problème, ouvrez **Dépannage guidé** et choisissez le symptôme observé. Le rapport d’intervention et le guide sont également accessibles dans le menu.

Ouvrez **Paramètres** en bas du menu. Décochez **Menu latéral** pour masquer le raccourci d’un outil. Vous pouvez toujours ouvrir cet outil depuis le catalogue. Cochez **Favori** pour placer sa carte en tête de l’accueil, repérée par une étoile. Chaque choix est enregistré pour votre compte Windows.

Dans **Système → Performances**, trois courbes affichent la charge du processeur, la mémoire utilisée et le temps d’activité du volume Windows sur les 60 dernières secondes. Le suivi démarre à l’ouverture et s’arrête quand vous quittez la page.

Pendant un ralentissement, choisissez **Lancer la mesure**. Après trois secondes, le bilan affiche les ressources à examiner en premier, avec leur conseil déplié. Cliquez sur une ressource pour consulter son seuil. Vous pouvez copier le bilan, le retrouver dans le rapport d’intervention ou le relancer. Si vous annulez une nouvelle mesure, le dernier résultat reste disponible.

## Utiliser l’application

1. Double-cliquez sur **Toolbox.exe**. L’exécutable peut être copié seul sur un autre PC Windows.
2. Pour un problème matériel, ouvrez **Diagnostic des périphériques** dans le catalogue ou choisissez **Dépannage guidé → Un appareil ne fonctionne plus**. Branchez et allumez l’appareil à vérifier puis cliquez sur **Lancer l’analyse**.
3. Si Windows signale un problème, lisez l’explication sous le nom de l’appareil. Dépliez **Étapes de résolution** pour suivre la procédure.
4. Pour un appareil désactivé que vous souhaitez utiliser, choisissez **Réactiver cet appareil** et confirmez. Windows peut demander l’autorisation d’un administrateur. Toolbox vérifie ensuite l’état du même appareil.
5. Pour partager le résultat d’un essai, cliquez sur **Copier le résumé**, puis collez le texte dans votre message. Le résumé indique les versions de Toolbox et de Windows, la date de l’analyse, les problèmes détectés et la dernière demande de réactivation de la session. Les appareils concernés y figurent sous leur modèle ou sous un intitulé générique.

L’inventaire et l’analyse restent sur le PC. Les résultats reflètent les signalements de Windows au moment de la vérification. Un appareil totalement invisible pour Windows, un faux contact ou une panne intermittente peuvent nécessiter un essai de branchement. Une aide est disponible sous les résultats.

### Ajouter un filigrane

Ouvrez **Fichiers → Ajouter un filigrane**. Déposez un PDF, un document Word (.docx) ou une image et saisissez votre texte. Choisissez **Texte unique** pour le centrer en diagonale ou le placer dans un coin, ou **Texte répété** pour couvrir la page. Réglez sa taille et son opacité, puis cliquez sur **Enregistrer une copie…**.

L’aperçu montre la photo ou la première page du PDF. Pour Word, **Simulation du placement** montre le motif aux proportions de la première section. Le document enregistré reste modifiable. Pour une image qui nécessite une conversion, consultez le format de sortie indiqué avant d’enregistrer. Tout le traitement s’effectue sur le PC.

### Comparer les doublons et choisir les copies à garder

Ouvrez **Fichiers → Rechercher les doublons**, puis choisissez le dossier à analyser. La recherche inclut ses sous-dossiers. **Doublons exacts** retrouve les fichiers de même contenu, y compris après un changement de nom ou d’extension. La présence d’une marque de téléchargement Windows sur une seule copie est indiquée dans la comparaison. Pour les photos fixes prises en charge, l’outil reconnaît aussi les conversions qui conservent les dimensions et tous les pixels affichés après prise en compte de l’orientation.

**Photos visuellement proches** permet de comparer les versions d’une même photo après une recompression ou un redimensionnement. Une image JPEG enregistrée en AVIF ou en WebP peut ainsi être proposée même si ses pixels ont légèrement changé. Les aperçus, les dimensions et les tailles aident à choisir les versions à garder. Un groupe de photos proches peut inclure des exemplaires également présents parmi les doublons exacts.

Choisissez un groupe pour comparer les aperçus, les formats réels, les dimensions et les tailles. Quand plusieurs noms longs ont le même début, les cartes mettent en avant leur terminaison. **Détails du fichier** affiche le nom complet, le dossier, la date et l’accès à l’Explorateur.

Au départ, toutes les copies sont conservées. Cochez les exemplaires à envoyer à la Corbeille et gardez-en au moins un dans chaque groupe. La barre en bas de la fenêtre indique combien de fichiers sont marqués dans la catégorie active et leur taille totale. **Vérifier ma sélection** affiche les fichiers à déplacer et ceux à conserver. Vous pouvez encore modifier votre choix avant de confirmer.

### Nettoyer les métadonnées avant un partage

Ouvrez **Fichiers → Nettoyeur de métadonnées** ou recherchez **EXIF** dans le catalogue. Déposez une ou plusieurs photos et documents ensemble, ou cliquez sur **Choisir des fichiers…**. Les formats acceptés sont JPEG, PNG, WebP, PDF, Word (.docx), Excel (.xlsx) et PowerPoint (.pptx). Le traitement et la vérification se font hors ligne, y compris pour les photos intégrées aux documents.

Pour un fichier, choisissez le nom de la copie. Pour un lot, cliquez sur **Enregistrer les copies nettoyées…** et choisissez un dossier. Sous les deux panneaux, chaque fichier a sa ligne et sa barre de progression. Vous y suivez le nettoyage, la vérification puis l’enregistrement.

Chaque copie reçoit le suffixe `-nettoye`. Si le nom existe déjà, l’outil ajoute un numéro, par exemple `photo-nettoye (2).jpg`. Chaque ligne indique les champs retirés de ce fichier (GPS, auteur, modèle d’appareil…), le nom de la copie, ou le motif d’un refus. Un fichier refusé laisse le lot se poursuivre. **Annuler** arrête le traitement et conserve les copies déjà terminées.

Le bilan indique les catégories retirées et le nombre d’images intégrées nettoyées, vignettes comprises. Les copies Office perdent aussi les paramètres propres à l’imprimante, qui peuvent identifier un appareil. Le texte, les commentaires, les notes et les révisions du document peuvent toujours mentionner une personne. L’outil explique son refus pour les fichiers chiffrés ou signés, les cartes PDF géoréférencées et les objets intégrés dont le contenu ne peut pas être vérifié. **Ouvrir le dossier** permet de retrouver la copie vérifiée. [Provenance du moteur PDF](vendor/qpdf/ORIGINE.md)

### Convertir plusieurs fichiers en une fois

Ouvrez le convertisseur **Images**, **Vidéos** ou **Audio**, puis déposez vos fichiers ensemble. Le bouton de sélection accepte aussi plusieurs fichiers avec Ctrl ou Maj. Choisissez un format commun, cliquez sur **Convertir le lot…** et choisissez une fois le dossier de destination.

La liste sous les réglages affiche une barre par fichier. Pour les images, elle suit la lecture, la conversion et l’enregistrement. En audio et en vidéo, elle affiche le pourcentage converti lorsque la durée est connue. Chaque copie enregistrée atteint 100 %.

Les copies reprennent le nom d’origine avec la nouvelle extension. Si un nom est déjà utilisé, Toolbox ajoute **(2)**, **(3)**, etc. Un fichier illisible est signalé et le lot continue. **Annuler** arrête le traitement et conserve les copies déjà terminées. **Ouvrir le dossier** permet de les retrouver.

Pour un lot audio, chaque copie utilise la piste par défaut de son fichier, ou la première piste audio disponible. Pour un lot d’images, choisissez un format animé comme GIF ou WebP si vous souhaitez conserver les animations.

### Convertir une image

Le panneau **Réglages de sortie** affiche le nom proposé pour la copie dès que vous choisissez un format. Dans la liste ouverte, une coche identifie le format sélectionné.

Depuis le catalogue ou la famille **Fichiers** du menu, ouvrez **Convertir une image**. Déposez un fichier dans la zone prévue ou cliquez sur **Choisir des images…**. Toolbox affiche un aperçu lorsqu’il est disponible, le format détecté, les dimensions et le nombre d’images. Choisissez le **Format de sortie**, cliquez sur **Convertir et enregistrer…**, puis indiquez où placer la copie. Après la conversion, cliquez sur **Ouvrir le dossier** pour retrouver le fichier dans l’Explorateur Windows. La conversion fonctionne hors ligne dès le premier lancement avec le seul fichier **Toolbox.exe**.

La liste propose 50 sorties, dont JPEG, PNG, WebP, GIF, AVIF, JPEG XL, TIFF, BMP, ICO, PDF et SVG. Les photos HEIC et HEIF sont acceptées en entrée et peuvent par exemple être enregistrées en JPEG. Un export SVG incorpore les pixels de l’image dans le document. Une icône est réduite si nécessaire pour tenir dans 256 × 256 pixels. En JPEG, les zones transparentes prennent un fond blanc.

Pour conserver les images successives d’une animation, choisissez par exemple GIF, WebP, AVIF ou JPEG XL. En passant à un format fixe, confirmez l’enregistrement de la première image. Le moteur intégré travaille en 8 bits par canal. Le PNG animé (APNG) et certaines compressions propriétaires nécessitent d’autres décodeurs. [Formats d’ImageMagick](https://imagemagick.org/formats/)

### Télécharger une vidéo YouTube

Ouvrez **Fichiers → Télécharger une vidéo YouTube** ou recherchez **YouTube** dans le catalogue. Collez l’identifiant de la vidéo ou son lien, puis cliquez sur **Analyser le lien**. Choisissez **Vidéo avec son (MP4)** pour sélectionner la résolution, ou **Audio seul (MP3)** pour enregistrer uniquement la piste sonore. Cliquez sur **Télécharger…**, puis choisissez le dossier et le nom du fichier dans **Enregistrer sous**.

La vue indique la progression et permet d’annuler. À la fin, **Ouvrir le dossier** affiche l’emplacement choisi. Le MP4 contient le son lorsque la vidéo en possède. L’outil nécessite une connexion Internet et Windows compatible x64. Les moteurs sont inclus dans l’exécutable. [Moteurs du téléchargement YouTube](vendor/YouTube/ORIGINE.md)

### Convertir une vidéo

Depuis le catalogue ou la famille **Fichiers** du menu, ouvrez **Convertir une vidéo**. Déposez la vidéo ou choisissez-la sur le PC. Sélectionnez le format de sortie, puis l’encodage vidéo. Par exemple, pour convertir un ancien fichier AVI ou WMV en MP4, choisissez **MP4** et **H.264**. Ces deux options sont présélectionnées.

| Format de sortie | Encodages vidéo | Encodage du son |
| --- | --- | --- |
| MP4 | H.264, H.265 (HEVC), AV1 | AAC |
| MKV | H.264, H.265 (HEVC), AV1, VP9 | AAC |
| WebM | VP9, AV1 | Opus |
| MOV | H.264, H.265 (HEVC) | AAC |
| AVI | MPEG-4 Part 2, Motion JPEG | MP3 |
| WMV | Windows Media Video 8, Windows Media Video 7 | WMA |

Laissez la qualité sur **Équilibrée** ou choisissez **Fichier plus petit** ou **Qualité élevée**. Cliquez sur **Convertir et enregistrer…** et indiquez où placer la copie. La page affiche la progression et permet d’annuler la conversion. Une fois la copie prête, **Ouvrir le dossier** permet de la retrouver.

L’outil convertit la piste vidéo principale et les pistes audio. Il accepte également les vidéos muettes. Les sorties AVI et WMV ramènent le son multicanal en stéréo. Si des sous-titres, des pièces jointes ou d’autres pistes vidéo seront écartés, un avertissement permet de revenir sur le choix avant l’enregistrement. La conversion s’effectue hors ligne avec le seul fichier **Toolbox.exe**, sous Windows 10 ou 11 compatible x64. [Moteur vidéo embarqué](vendor/FFmpeg/ORIGINE.md)

### Convertir un fichier audio

Depuis le catalogue ou la famille **Fichiers** du menu, ouvrez **Convertir un fichier audio**. Déposez votre fichier et choisissez le format de sortie. **MP3** et la qualité **Équilibrée** sont présélectionnés. Pour une source qui contient plusieurs pistes, vous pouvez choisir celle à convertir. Cela permet aussi d’extraire le son d’une vidéo.

| Usage | Sorties proposées |
| --- | --- |
| Musique et livres audio | MP3, M4A (AAC ou Apple Lossless), M4B, AAC (ADTS ou LOAS/LATM), Ogg Vorbis, Ogg Opus, WMA, MP2, WebM audio |
| Audio PCM et compression sans perte | WAV, FLAC, AIFF, WavPack, True Audio, Ogg FLAC, Matroska audio (FLAC), CAF, AU, Sony Wave64, IRCAM, SoX |
| Voix et formats spécialisés | Dolby Digital (AC3), Dolby Digital Plus (EAC3), Speex, AMR, AMR-WB, GSM, SBC, Creative Voice (VOC), CRI ADX |

En entrée, le moteur accepte aussi des formats comme Monkey’s Audio (APE), Musepack, TAK, Shorten, DSD (DSF), ainsi que des modules musicaux MOD, XM, S3M et IT. La lecture dépend de l’encodage contenu dans le fichier. Le réglage **Qualité** apparaît pour les formats à compression réglable. Les formats destinés à la voix, comme AMR et GSM, utilisent du son mono. Pour conserver la précision d’un WAV entier 32 bits, choisissez WAV ou WavPack.

Cliquez sur **Convertir et enregistrer…** pour choisir le nom et le dossier de la copie. Vous pouvez suivre la progression, annuler ou ouvrir le dossier du fichier enregistré. Le convertisseur fonctionne hors ligne sur Windows compatible x64 avec le moteur déjà intégré à l’exécutable.

### Diagnostiquer un PC lent

Dans **Dépannage guidé**, choisissez **Mon PC est lent**, reproduisez le ralentissement puis lancez la mesure. L’outil relève la charge du processeur sur un court intervalle, la mémoire physique disponible et l’espace libre du volume de Windows. Les détails techniques permettent de relire les valeurs et les seuils utilisés. Refaites la mesure après avoir suivi un conseil pour comparer les observations dans le rapport de session.

### Relire ou partager une intervention

Ouvrez **Rapport d’intervention** depuis le menu. Les contrôles effectués pendant la session y apparaissent avec leur heure, leur résultat et les mesures disponibles. Les événements USB y figurent sous des descriptions partageables. **Copier le rapport** place le texte dans le presse-papiers. Copiez-le avant de fermer l’application si vous souhaitez conserver une trace.

### Vérifier et réparer Windows

La page **Dépannage guidé** indique **Mode standard** ou **Mode administrateur** selon les droits effectifs de Toolbox. Dans **Intégrité de Windows**, choisissez une vérification des fichiers protégés (SFC) ou du magasin de composants (DISM). Les actions de réparation sont également disponibles. Lisez leur description et confirmez la réparation souhaitée. En mode standard, Windows peut demander une autorisation pour exécuter l’action.

La console de Windows présente le résultat détaillé. À la fin, **Lire le journal** affiche les dernières lignes de CBS ou de DISM dans Toolbox. Ce journal local peut concerner plusieurs opérations. Le rapport partagé reprend uniquement le suivi de la commande. Une opération DISM peut prendre plusieurs minutes et utiliser Windows Update pour récupérer les composants nécessaires. Après une réparation, relancez la vérification et reproduisez le symptôme. [Référence SFC](https://learn.microsoft.com/fr-fr/windows-server/administration/windows-commands/sfc) · [Référence DISM](https://learn.microsoft.com/fr-fr/windows-hardware/manufacture/desktop/repair-a-windows-image?view=windows-11)

### Mesurer le débit Internet

Dans le menu latéral, ouvrez **Réseau → Test de débit**, puis cliquez sur **Lancer le test**. La réception et l’envoi s’affichent en Mbit/s et en Mo/s (80 Mbit/s correspondent à 10 Mo/s). La latence HTTPS est la médiane de cinq allers-retours vers Cloudflare. La gigue mesure la variation moyenne entre deux allers-retours successifs. Le résultat indique aussi la durée des mesures et le volume de données de test transféré dans chaque sens.

Pendant le test, l’écran indique l’étape en cours. Une fois les deux débits mesurés, les barres les comparent sur la même échelle. Si l’envoi atteint la moitié du débit en réception, sa barre est deux fois plus courte.

L’**historique** conserve les dix derniers tests terminés dans votre profil Windows, même après fermeture de Toolbox. Chaque entrée indique la date, l’heure et la liaison du test (Wi-Fi, Ethernet ou autre type identifié par Windows). Pour un test Wi-Fi, le nom du réseau (SSID) apparaît à côté de la date lorsque Windows le fournit. Ce nom est lu sur la carte utilisée et conservé sur le PC.

Ouvrez **Détails de la connexion et des transferts**, ou dépliez une ligne de l’historique, pour consulter séparément l’IPv4 publique, l’IPv6 publique et le FAI. Si le serveur de mesure fournit une seule adresse, Toolbox interroge le service icanhazip de Cloudflare pour l’autre famille. Une famille inaccessible apparaît comme « indisponible ». Les adresses correspondent aux sorties Internet du PC au moment du test. IPv4 et IPv6 peuvent emprunter des cartes différentes ou passer par un VPN ou un proxy. Les anciens tests affichent l’adresse enregistrée à l’époque.

Chaque essai transfère jusqu’à 100 Mo de données de test, envoi et réception compris. Les données envoyées sont générées en mémoire. Vous pouvez cliquer sur **Annuler** ou quitter la page pour arrêter la mesure. Si un transfert échoue, les mesures déjà terminées restent affichées et **Relancer le test** démarre un nouvel essai.

### Voir les appareils connectés au réseau local

Ouvrez **Réseau → Appareils du réseau**, choisissez votre connexion Wi-Fi ou Ethernet, puis cliquez sur **Rechercher les appareils**. Chaque ligne indique une adresse IPv4 et l’adresse MAC obtenue sur cette connexion lorsqu’elle est disponible. **(ce PC)** désigne votre ordinateur. Si la passerelle configurée répond sans fournir de nom, elle apparaît sous **Passerelle du réseau**.

Cliquez sur un en-tête pour trier la colonne, puis cliquez à nouveau pour inverser l’ordre. Le filtre accepte une partie du nom, de l’IP ou de la MAC, par exemple `192.168.1.` ou `3C:AA:BB`.

**Nom inconnu** signifie que l’adresse a répondu, mais que Windows et les annonces UPnP locales n’ont fourni aucun nom. Sélectionnez une ligne pour ouvrir sa fiche. Un téléviseur ou une box compatible UPnP peut y indiquer son nom usuel, son fabricant et son modèle. [Découverte des voisins sous Windows](https://learn.microsoft.com/en-us/windows/win32/api/netioapi/nf-netioapi-resolveipnetentry2) · [Découverte UPnP](https://openconnectivity.org/developer/specifications/upnp-resources/upnp/)

Sous **Ports TCP**, la fiche de ce PC présente ses ports en écoute sur la connexion choisie. Pour un autre appareil, la fiche indique le port ayant répondu à la lecture de sa description UPnP et les ports distants des connexions TCP actuellement établies avec ce PC, lorsqu’ils sont disponibles. Un port distant peut aussi être celui d’un client. Pour vérifier un numéro précis, saisissez-le et cliquez sur **Tester ce port**. Le résultat indique si une connexion TCP aboutit depuis ce PC au moment du test. [Connexions TCP observées par Windows](https://learn.microsoft.com/en-us/dotnet/api/system.net.networkinformation.ipglobalproperties.getactivetcpconnections)

Le relevé couvre le sous-réseau IPv4 visible depuis la carte choisie. Un appareil en veille, sur le Wi-Fi invité, sur un autre sous-réseau ou uniquement en IPv6 peut manquer. Pour comparer, ouvrez la liste des **clients actuellement connectés** dans l’interface de la box. Vous pouvez annuler la recherche et consulter les réponses déjà reçues, ou la relancer pour mettre la liste à jour.

### Retrouver les noms des appareils auprès de la box

1. Dans **Réseau → Appareils du réseau**, sélectionnez votre connexion, puis **Lire depuis la box… → Ouvrir l’interface de la box…**.
2. Connectez-vous dans l’interface habituelle de la box. Affichez la rubrique **Appareils connectés**, **Clients** ou son équivalent, puis cliquez sur **Lire la liste affichée**. Si la liste comporte plusieurs pages, utilisez **Ajouter cette page** avant de passer à la suivante, puis **Terminer la lecture**.
3. Vérifiez les noms, les adresses et les états dans l’aperçu, puis cliquez sur **Importer la liste**. L’onglet **Depuis la box** présente les lignes retenues. Une ligne explicitement hors ligne est écartée. **Non précisé** signifie que la liste n’indiquait aucun état reconnu.
4. Dans **Depuis ce PC**, un appareil auparavant inconnu récupère le nom associé à sa MAC dans le relevé de la box. Sa fiche en indique la provenance. Vous pouvez lire la box avant ou après la recherche du PC. Une nouvelle importation remplace la précédente pour la connexion sélectionnée.

La lecture utilise les tableaux et les fiches affichés par l’interface locale. La compatibilité dépend de ce que le modèle et son logiciel rendent visible. Si l’interface utilise une autre adresse locale, saisissez-la dans la fenêtre de lecture. Si la gestion se fait depuis une application mobile ou si la page est illisible, utilisez **Utiliser une liste copiée**, collez les clients avec leurs en-têtes, puis cliquez sur **Afficher l’aperçu**. Cette option fonctionne aussi sur un PC dépourvu du navigateur intégré WebView2. [Runtime Microsoft WebView2](https://learn.microsoft.com/fr-fr/microsoft-edge/webview2/concepts/distribution)

La correspondance utilise une MAC complète et un nom sans ambiguïté. Vérifiez que le téléphone présente la même adresse Wi-Fi privée dans les deux relevés. Un équipement nommé dans la box mais sans MAC peut figurer dans son onglet avec son IP. Les listes importées sont conservées en mémoire pour la connexion sélectionnée.

### Dépanner une connexion

Ouvrez **Réseau → Dépannage réseau** puis **Lancer le diagnostic**. Toolbox examine les cartes actives et, si le PC est connecté à un réseau, demande une courte réponse au serveur de test Microsoft. Le résultat indique la prochaine action, par exemple reconnecter le Wi-Fi, valider un portail de connexion ou vérifier la box. Un réseau d’entreprise peut filtrer ce serveur. [Test de connectivité de Microsoft](https://learn.microsoft.com/fr-fr/troubleshoot/windows-server/networking/troubleshoot-ncsi-guidance)

Quand les noms de test échouent à la résolution, **Vider le cache DNS** permet à Windows de redemander leurs adresses. Lorsqu’une carte en configuration automatique attend une adresse IP, **Renouveler l’adresse IP** cible la carte indiquée. Cliquez sur la correction souhaitée puis acceptez l’autorisation Windows si elle est demandée. Toolbox affiche le résultat de la commande et vérifie de nouveau la connexion. [Commandes réseau de Windows](https://learn.microsoft.com/fr-fr/windows-server/administration/windows-commands/ipconfig)

Les détails du contrôle indiquent ce que l’outil a pu vérifier sur la liaison, les adresses, la passerelle, la résolution des noms et la réponse du serveur. Après une correction, retrouvez les observations avant et après l’opération dans le rapport.

### Voir qui est branché sur chaque hub USB

Ouvrez **Carte USB** dans le menu. Dépliez le contrôleur, le hub racine du PC puis les hubs raccordés en cascade. Chaque appareil apparaît sous son hub, avec le numéro du port lorsque Windows le fournit. Cliquez sur un appareil pour lire son chemin complet et son état. Cliquez sur **Actualiser la carte** après avoir déplacé un câble. Depuis une fiche de diagnostic, **Voir sur la carte USB** sélectionne l’appareil s’il est encore présent.

La carte représente les branchements détectés, y compris ceux des composants USB internes. La numérotation est locale à chaque hub. La correspondance avec une prise en façade ou à l’arrière dépend du PC. Une branche dont Windows ne fournit pas le parent apparaît sous **Rattachement indéterminé**.

Sur un appareil multifonction, la fiche signale aussi les fonctions que Windows indique en erreur. Par exemple, une webcam peut être reconnue alors que sa fonction vidéo manque de pilote. Sélectionnez-la pour lire le code Windows et les étapes de résolution de la fonction concernée. [Interfaces des périphériques USB composites](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/standard-usb-identifiers)

### Repérer une déconnexion intermittente

Ouvrez **Carte USB** une première fois, puis utilisez normalement l’accessoire. Le suivi continue pendant que vous consultez les autres pages de Toolbox. Dépliez **Activité des branchements** pour voir les apparitions, les disparitions et les retours horodatés. Si une même entrée disparaît plusieurs fois, essayez de changer un seul élément à la fois, par exemple le câble, puis comparez les observations.

**Suspendre le suivi** arrête les relevés automatiques. **Reprendre le suivi** établit un nouvel état de départ. Toutes les observations de la session sont consultables sur la carte et le rapport conserve la chronologie de la session sous des libellés partageables. La fermeture de l’application arrête le suivi. Windows signale un changement de périphériques et Toolbox compare les inventaires successifs. Une coupure suivie d’un retour entre deux relevés peut passer inaperçue. [Notifications de changement de périphériques Windows](https://learn.microsoft.com/en-us/windows/win32/devio/dbt-devnodes-changed)

### Suivre un appareil déplacé et son port COM

Ouvrez **Carte USB** avant de déplacer l’appareil. La carte se met à jour lors des notifications de branchement de Windows. **Actualiser la carte** permet aussi de déclencher la comparaison. Sous l’arbre, **Suivi des changements de port** présente l’ancien et le nouveau branchement. Toolbox indique « Même appareil reconnu » si Windows signale un identifiant unique et que l’identifiant d’instance correspond. Pour un adaptateur série, comparez les ports COM indiqués et choisissez le port actuel dans votre logiciel.

La fiche de l’adaptateur affiche également ses ports COM actifs dès le premier relevé, y compris ceux des interfaces enfants que Windows permet de lui rattacher. Pour un adaptateur à plusieurs interfaces, comparez les affectations proposées avec celle attendue par votre logiciel. Le rapport reprend les ports COM actuels dès le premier relevé et conserve les changements suivants.

Les relevés de la session restent en mémoire jusqu’à la fermeture de Toolbox. L’outil consulte aussi les anciennes installations encore enregistrées par Windows. Un autre exemplaire du même modèle peut avoir été utilisé auparavant. Vérifiez l’emplacement et les réglages avant de conclure à un déplacement.

Si une ancienne entrée déconnectée vous gêne, ouvrez **Examiner l’ancienne installation** lorsqu’il est proposé. Confirmez l’entrée concernée avant de demander son retrait. Toolbox vérifie de nouveau les deux installations après l’autorisation administrateur. Windows retire l’ancienne instance et ses fonctions associées et conserve le paquet de pilotes. Plusieurs correspondances possibles, un hub ou une entrée active excluent ce retrait. Le nettoyage ne réattribue pas automatiquement un numéro COM.

### Retrouver un périphérique USB inconnu

Si Windows affiche le code 43 avec une erreur de réinitialisation du port ou de lecture de la description USB, ouvrez **Retrouver cet appareil** sur sa fiche. Laissez le branchement en place jusqu’à ce que l’outil demande de retirer un accessoire. Cliquez sur **Vérifier le débranchement**, puis suivez les indications pour essayer la même prise avec le même accessoire. Après chaque vérification, **Copier le résumé** inclut l’observation du test.

La fiche affiche le repère du port attribué par Windows lorsqu’il est disponible. Les noms retrouvés dans les anciens branchements au même emplacement sont des pistes à confirmer. L’assistant relit l’inventaire après chaque manipulation. Si l’alerte revient, il propose des essais séparés de la prise et du câble. Un échec de communication USB peut survenir avant que l’appareil transmette son modèle. [Exemple de diagnostic USB de Microsoft](https://learn.microsoft.com/windows-hardware/drivers/usbcon/case-study--troubleshooting-an-unknown-usb-device-by-using-etw-and-netmon)

La réactivation intégrée utilise PnPUtil, disponible pour cette action à partir de Windows 10 version 2004 et sur Windows 11. Sur les versions antérieures, le guide indique comment réactiver l’appareil dans le Gestionnaire de périphériques. [Documentation Microsoft sur PnPUtil](https://learn.microsoft.com/fr-fr/windows-hardware/drivers/devtest/pnputil-command-syntax)

## Ajouter un outil

1. Ajoutez une vue nommée dans `src/Fenetre.xaml`, à côté de `SpeedPage`, et placez sa logique dans un fichier C# du dossier `src`.
2. Dans `CreateToolCatalog()` de `src/ToolCatalog.cs`, déclarez une `NavigationPage` sur le modèle du test de débit et incluez-la dans la liste retournée. Donnez-lui un nom de bouton unique, une vue, une icône, ses libellés et une catégorie. Associez l’outil à la famille appropriée dans le catalogue et vérifiez son accès depuis la recherche et le menu latéral.
3. Si l’outil doit charger des données à l’ouverture ou arrêter un travail en cours à la sortie, renseignez `OnOpen` ou `OnLeave`. Le bouton principal de la vue peut être indiqué dans `PrimaryAction` pour recevoir le focus depuis le catalogue.

## Compiler et vérifier

Le projet utilise C#, WPF et .NET Framework 4.6 ou ultérieur. Le script utilise le compilateur du .NET Framework de Windows. Depuis le dossier du projet, dans PowerShell, exécutez la première commande pour produire l’exécutable et la seconde pour lancer les contrôles.

~~~powershell
.\compiler.ps1
.\compiler.ps1 -Tester
~~~

Les contrôles couvrent les explications, les critères de réactivation, la vérification du résultat, l’inventaire réel en lecture seule et le parcours graphique sur des données de test. Ils vérifient également les conversions d’images, les animations, la fermeture pendant une lecture et la conservation des fichiers en cas d’échec. Pour travailler dans Visual Studio avec les références .NET Framework 4.6, ouvrez le fichier Toolbox.csproj.

Les deux méthodes de compilation incorporent les moteurs et leurs notices dans l’exécutable. Les contrôles audio et vidéo encodent de courts extraits, relisent les fichiers produits et vérifient la protection des originaux. Les contrôles audio vérifient aussi le choix de la piste et comparent les échantillons de plusieurs formats sans perte. [Provenance d’ImageMagick](vendor/ImageMagick/ORIGINE.md) · [Provenance de FFmpeg](vendor/FFmpeg/ORIGINE.md)

### Publier une nouvelle version sur GitHub

Le workflow [Compiler et tester Toolbox](.github/workflows/toolbox.yml) compile le logiciel sous Windows et lance les tests à chaque push et pour les pull requests. Vous pouvez aussi le lancer depuis l’onglet **Actions** avec **Run workflow**. Conservez le dossier `vendor/` dans le dépôt Git pour que la compilation retrouve les moteurs embarqués.

Pour publier une version, créez un tag au format `vX.Y.Z` sur le commit à distribuer et poussez ce tag sur GitHub. Une fois les tests réussis, le workflow joint **Toolbox.exe** à la version dans **Releases**. Le lien en haut de ce README télécharge directement l’exécutable de la dernière version.

Les signalements sont lus via SetupAPI et le gestionnaire de configuration de Windows. Les explications correspondent aux codes du Gestionnaire de périphériques. [Référence Microsoft des codes](https://learn.microsoft.com/windows-hardware/drivers/install/device-manager-error-messages)
