# Convertir une vidéo

Depuis le catalogue ou la famille **Fichiers** du menu, ouvrez **Convertir une vidéo**. Déposez la vidéo ou choisissez-la sur le PC. Sélectionnez le format de sortie, puis l’encodage vidéo. Par exemple, pour convertir un ancien fichier AVI ou WMV en MP4, choisissez **MP4** et **H.264**. Ces deux options sont présélectionnées.

| Format de sortie | Encodages vidéo | Encodage du son |
| --- | --- | --- |
| MP4 | H.264, H.265 (HEVC), AV1 | AAC |
| MKV | H.264, H.265 (HEVC), AV1, VP9 | AAC |
| WebM | VP9, AV1 | Opus |
| MOV | H.264, H.265 (HEVC) | AAC |
| AVI | MPEG-4 Part 2, Motion JPEG | MP3 |
| WMV | Windows Media Video 8, Windows Media Video 7 | WMA |

Laissez la qualité sur **Équilibrée** ou choisissez **Fichier plus petit** ou **Qualité élevée**. Cliquez sur **Convertir et enregistrer…** et indiquez où placer la copie. La page affiche la progression et permet d’annuler la conversion. Une fois la copie prête, **Ouvrir le dossier** permet de la retrouver.

L’outil convertit la piste vidéo principale et les pistes audio. Il accepte également les vidéos muettes. Les sorties AVI et WMV ramènent le son multicanal en stéréo. Si des sous-titres, des pièces jointes ou d’autres pistes vidéo seront écartés, un avertissement permet de revenir sur le choix avant l’enregistrement. La conversion s’effectue hors ligne avec le seul fichier **Toolbox.exe**, sous Windows 10 ou 11 compatible x64. [Moteur vidéo embarqué](../../vendor/FFmpeg/ORIGINE.md)

## Convertir plusieurs vidéos

Déposez les vidéos ensemble ou sélectionnez-les avec Ctrl ou Maj. Choisissez un format commun, puis **Convertir le lot…** et le dossier de destination. Chaque ligne affiche le pourcentage converti lorsque la durée est connue et atteint 100 % une fois la copie enregistrée.

Les copies reprennent le nom d’origine avec la nouvelle extension. Si un nom est déjà utilisé, Toolbox ajoute **(2)**, **(3)**, etc. Un fichier illisible est signalé et le lot continue. **Annuler** arrête le traitement et conserve les copies déjà terminées. **Ouvrir le dossier** permet de les retrouver.
