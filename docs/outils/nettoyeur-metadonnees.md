# Nettoyeur de métadonnées

Ouvrez **Fichiers → Nettoyeur de métadonnées** ou recherchez **EXIF** dans le catalogue. Déposez une ou plusieurs photos et documents ensemble, ou cliquez sur **Choisir des fichiers…**. Les formats acceptés sont JPEG, PNG, WebP, PDF, Word (.docx), Excel (.xlsx) et PowerPoint (.pptx). Le traitement et la vérification se font hors ligne, y compris pour les photos intégrées aux documents.

Pour un fichier, choisissez le nom de la copie. Pour un lot, cliquez sur **Enregistrer les copies nettoyées…** et choisissez un dossier. Sous les deux panneaux, chaque fichier a sa ligne et sa barre de progression. Vous y suivez le nettoyage, la vérification puis l’enregistrement.

Chaque copie reçoit le suffixe `-nettoye`. Si le nom existe déjà, l’outil ajoute un numéro, par exemple `photo-nettoye (2).jpg`. Chaque ligne indique les champs retirés de ce fichier (GPS, auteur, modèle d’appareil…), le nom de la copie, ou le motif d’un refus. Un fichier refusé laisse le lot se poursuivre. **Annuler** arrête le traitement et conserve les copies déjà terminées.

## Vérifier le résultat

Le bilan indique les catégories retirées et le nombre d’images intégrées nettoyées, vignettes comprises. Les copies Office perdent aussi les paramètres propres à l’imprimante, qui peuvent identifier un appareil. Le texte, les commentaires, les notes et les révisions du document peuvent toujours mentionner une personne. L’outil explique son refus pour les fichiers chiffrés ou signés, les cartes PDF géoréférencées et les objets intégrés dont le contenu ne peut pas être vérifié. **Ouvrir le dossier** permet de retrouver la copie vérifiée.
