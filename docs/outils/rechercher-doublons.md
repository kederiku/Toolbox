# Rechercher les doublons

Ouvrez **Fichiers → Rechercher les doublons**, puis choisissez le dossier à analyser. La recherche inclut ses sous-dossiers. **Doublons exacts** retrouve les fichiers de même contenu, y compris après un changement de nom ou d’extension. La présence d’une marque de téléchargement Windows sur une seule copie est indiquée dans la comparaison. Pour les photos fixes prises en charge, l’outil reconnaît aussi les conversions qui conservent les dimensions et tous les pixels affichés après prise en compte de l’orientation.

**Photos visuellement proches** permet de comparer les versions d’une même photo après une recompression ou un redimensionnement. Une image JPEG enregistrée en AVIF ou en WebP peut ainsi être proposée même si ses pixels ont légèrement changé. Les aperçus, les dimensions et les tailles aident à choisir les versions à garder. Un groupe de photos proches peut inclure des exemplaires également présents parmi les doublons exacts.

## Choisir les copies à garder

Choisissez un groupe pour comparer les aperçus, les formats réels, les dimensions et les tailles. Quand plusieurs noms longs ont le même début, les cartes mettent en avant leur terminaison. **Détails du fichier** affiche le nom complet, le dossier, la date et l’accès à l’Explorateur.

Au départ, toutes les copies sont conservées. Cochez les exemplaires à envoyer à la Corbeille et gardez-en au moins un dans chaque groupe. La barre en bas de la fenêtre indique combien de fichiers sont marqués dans la catégorie active et leur taille totale. **Vérifier ma sélection** affiche les fichiers à déplacer et ceux à conserver. Vous pouvez encore modifier votre choix avant de confirmer.
